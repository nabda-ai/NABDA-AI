NABDA-AI website starter
========================

Files:
- index.html
- style.css
- script.js

How to preview:
1. Keep the three files in the same folder.
2. Keep your image assets in this same folder as requested.
3. Open index.html in a modern browser, or use VS Code Live Server.

Assets:
- The HTML references numbered image assets by trying common extensions (.jpg, .jpeg, .png, .webp) at runtime and keeps an online fallback if no local match is found.
- The 3D models are referenced as 8.glb and 9.glb. If your actual filenames differ, edit those two src attributes in index.html.
- The Google model-viewer component is loaded from unpkg and therefore requires internet access.
- Google Fonts and the fallback stock photography require internet access.

Contact:
- The contact form opens a pre-filled email draft; it does not send directly without a backend.
- Contact URLs are the ones supplied for NABDA-AI.
